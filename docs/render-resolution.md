# 示例歌词渲染分辨率（实验）

2026-11-16：用户要求尝试降低渲染分辨率。真实歌曲和开发／演示共用设置：
**设置 → 歌词渲染分辨率（实验）→ 100% / 75% / 50%**。
默认及旧设置均为100%，选择会持久保存。播放时间、歌词偏移和seek规则不变。

该功能只在sample实现，不改变FoliaLyricsView公共契约或库的默认画质。
降低歌词舞台的物理尺寸与density，使用较小离屏层，再一次放大到原舞台尺寸；
播放器按钮、进度条和歌曲信息保持原分辨率。使用宿主原有sp↔dp转换，
保留Android非线性字体缩放；点击由同一图层变换映射。RTL采用物理左上原点。
内部字素计时、完整段落塑形和动画采样没有被删除。

| 档位 | 400×300物理舞台的内部尺寸 | 内部像素数 |
| --- | --- | --- |
| 100% | 400×300 | 120000 |
| 75% | 300×225 | 67500 |
| 50% | 200×150 | 30000 |

这是允许损失画质的可选实验：文字、字幕和辉光边缘会更柔；尺寸取整、字体栅格和
最小模糊半径可能造成局部位置、拟合或覆盖差异。像素数下降不等于整帧耗时或PSS
按相同比例下降。100%继续用于原版Folia视觉验收，低档位不替代原定验收标准。

## 已完成验证

- Windows x64/JDK21离屏Compose实际运行：100%与原始直接舞台逐像素相同。
- 400×300、宿主density2、RTL、自定义字体转换：三档实际内部尺寸、逻辑视口、
  字体转换和真实指针坐标通过。首版RTL右对齐错误已修复，原坐标断言保持。
- 两主题×三档×五个时间点共30张合成PNG；每帧暂停双采、反向seek重访和
  380→800→380恢复严格相同。固定Latin许可字体；中文使用平台fallback，
  因而这些画面不作为跨设备字体golden，也不构成新增上游等价验收。
- 两种示例入口的设置、暂停位置不变、旧设置兼容及存储往返通过；原布局、
  Rust开关、播放器会话和错误恢复相关检查通过。
- Android共享代码及默认带arm64/x86_64 Rust的debug APK构建、签名检查通过。
  新档位未在Android真机运行：验证期间设备已断开，未替换用户正在播放的应用。

画面对照、哈希及条件见[证据](../verification/playback-stutter/render-resolution/README.md)。
构建：`./gradlew.bat :sample:android-app:assembleDebug`；本轮留存测试包在
`build/outputs/folia-sample-resolution-debug.apk`。Android与Desktop使用相同sample设置。

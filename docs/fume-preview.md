# 浮名 Fume 文章镜头校准预览

固定 Folia v0.7.26 / cc6226e464050a456a2913e062374f23d3844cc5，AGPL-3.0-only。
这是实际整曲文章主题，仍未通过最终视觉验收。

示例的显示设置 → 歌词主题 → 浮名，真实歌曲与开发／演示均可用。
可调文章字号、保留比例、步进／平滑镜头、速度、辉光和打印符号，偏好持久化。
默认仍是选择音频的用户流程，库不创建播放器或演示时钟。

```kotlin
FoliaLyricsView(
    lyrics = lyrics,
    playback = { snapshot },
    style = FoliaStyle.Fume(FumeTuning()),
    onLineClicked = { line -> playerSeek(line.start + offsetMillis) },
)
```

入口使用实际 lyrics-core0.5.0。保留原对象、嵌套伴唱、源时间与内部片段时钟；
无逐词数据使用上游的整句均匀字素派生时间，不能称真实逐词标注。
完整段落塑形后按内部进度绘制；不逐UTF-16字符塑形，不复用Classic舞台。
副歌只接显式顶层 `chorusLineIndices`，关键词色只接 `wordColors`。
`layoutSeed` 默认 `Fume`；这些歌级输入不写入全局偏好。
字号同时包含主题倍率、FoliaTypography.scale 与系统fontScale，各计算一次。

布局、文字及相机节点在可取消的后台任务准备。输入、字体、尺寸或镜头配置变化会
取消旧任务并显示“正在准备浮名文章…”，新结果不会覆盖更新输入。
准备错误可见，并通过FoliaStatus诊断报告。字幕／保留比例／打印／配色变化不错误
重置准备状态。离屏或卸载清理静态图缓存引用；取消、卸载后不保留动画任务。
同一歌曲的保留时长只在hold设置变动时重算，不逐帧排序整首歌词。

媒体快照是唯一时间源，offset仅减一次。镜头由内容事件和连续积分节点重建，
不累计显示帧。原版墙钟浮动改用媒体时间原点0，暂停冻结、seek可逆；尾部继续媒体
浮动而非冻结最后一帧。减少动态跳到静态焦点／总览并关闭打印符号；Minimal关闭
辉光与打印。Reduced目前与Standard同绘制精度，没有宣称独立降采样收益。
点击与长按逆变换到实际文章行盒，按逆绘制顺序返回原来源对象；空白区域穿透。
原版未来文字和已读文字仍有低alpha，均按可见内容保留命中。
有限等待球和字幕沿用共享规则，未将无歌词当间奏。

验证见 `verification/fume-public/README.md`。216公共帧与独立文章舞台逐像素一致；
上游函数管线对照全非背景含低alpha MAE12.016782，镜头屏幕峰差15.933273px、
scale峰差0.056221。原短桥接／总览的RAF离散响应与连续模型仍有差异，文字光栅、
复杂字体和完整原React挂载生命周期仍待对照；不能据此宣布原版等价。
Android构建与JVM离屏通过，未启动真实Desktop窗口、未安装或操作Android设备。
整曲准备已有120行场景及字号恢复测试；这些不是设备内存／帧率测量。
